v176 — 草原の復活後に王へ報告できない不具合

原因: v141の全滅後に前Areaへ戻す処理が、草原の戦闘内復活にも実行されていた。
モブホーク戦は続行しているのに冒険データだけがArea3へ戻り、その後の勝利で報告待ちにならなかった。

修正:
・復活対象・復活中・終了済み戦闘では敗北によるArea巻き戻しを実行しない。
・復活回数を使い切った通常敗北の巻き戻しは維持。
・草原のボス撃破後会話が保留中または完了済みで、草原未報告のセーブは報告待ちへ補正。
・補正はロード時、HOME／城の描画時に実行。報告・報酬は重複実行しない。
・未撃破のセーブや砂漠以降の進行には触れない。

確認:
node tests/grass-rescue-v176.cjs
node tests/adventure-report.cjs
node --check js/game.js
git diff --check

ビルド: node scripts/build-v174.cjs
