MOB QUEST v145 REGRESSION REPORT

ROOT CAUSE
- v144 disabled browser wrapping with white-space:pre.
- Historical CSS still had max-width:72vw!important, while JS measured for a wider bubble.
- Result: longer Japanese lines were intentionally kept on one line, then clipped outside the real bubble.

FIX
- Dialogue lines are now split by actual canvas pixel width, not character count alone.
- Semantic break scoring favors punctuation / clause particles and rejects 1-3 character orphan tails.
- storySayLine sets both width and max-width inline !important from the real scene width, defeating stale 72vw clamps.
- CSS fallback restored to pre-line; Safari may no longer clip a line merely because authored text is long.
- Story, subquest, battle dialogue and castle-report page helpers use the same measured splitter.
- Sea quest 5 dialogue is manually authored into natural pages.

PRESERVED
- v144 Mob Wave HP / 2-3 actions / Abyss Soldier escorts / enemy HP HUD.
- v143 and earlier systems remain present.
