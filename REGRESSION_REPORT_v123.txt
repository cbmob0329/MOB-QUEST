MOB QUEST v148 REGRESSION REPORT

ROOT CAUSE
- v146 used canvas/font estimates, then the real Safari DOM was still allowed to wrap story text.
- Subquests call storySay(), so the intended fix path was correct, but the final DOM could still create one/two-character orphan lines.
- v147 only added a separate facility/dialog path and did not remove this subquest DOM-wrap failure.

FIX
- Subquest/story dialogue is measured with the actual rendered DOM font.
- The individual bubble stretches first up to the safe phone width.
- Chosen lines render as nowrap block spans, so Safari cannot create an extra line after the decision.
- Only lines that truly exceed the safe phone width are semantically split.
- 1-3 character orphan tails are rejected/rebalanced.
- Authored two-line dialogue is preserved exactly.
- Sea Q3/Q5 examples are reasserted, including:
  有名な戦いには必ず
  モブジョーンズの功績があるぞ

PRESERVED
- v147 facility/Mob Pink adaptive dialogue.
- v146 enemy HUD/Jones sizing.
- v145-v141 battle, passive, shop, quest, reward and story systems.
