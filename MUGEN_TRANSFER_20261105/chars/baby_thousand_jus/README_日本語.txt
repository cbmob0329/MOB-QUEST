【入力】
F=相手方向、B=後ろ、D=下、U=上、DF=下前。方向＋は方向保持とボタン押下です。
x/y/z/a/b/cはMUGENの論理ボタンで、実際のキーはホスト設定に従います。
通常: x / y / z（立ち・しゃがみ・空中、各同ボタン3段）
無料4技: F+z / B+z / F+y / B+y
1ゲージ技（各1000）: F+a / B+a
2ゲージ技（各2000）: F+b / B+b
通常投げ: F+c / B+c
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U、空中で離して再度Uで追加1回。
通常連撃は命中・受付時間などの条件があります。押しっぱなしでの自動3連ではありません。

【キャラ固有の注意】
1枠でベビードラゴンから千年竜へ自動進化します。HP50%以下を記録し、安全な地上復帰時に1ラウンド1回変身。HP・ゲージを補充しません。
原則地上始動。F+yは空中でも1滞空1回。方向なし空中cは1滞空1回の下降滑空です。
下方向は前後より優先。通常1・2段中は方向付きx/y/zより通常連撃継続を優先します。
千年竜の歩行には新しい左右脚の通過姿勢を追加しています。移動速度そのものは変更していません。
今回の起動・対戦結果は未確認です。自キャラ内の鏡像投げ受けは形態対応済みですが、外部キャラが指定する特殊状態ではベビー側の姿勢になる場合があります。

【共通の注意】
無料攻撃は命中80・ガード20を基準に、1発動の合計獲得上限240。移動のみ・空振りは獲得なし。
超必殺は開始時にゲージを消費し、命中による自己ゲージ獲得はありません。
浮かせ後の追撃には共有上限があり、攻撃側の着地や技の切替だけでは回復しません。
相手の体格・重力・距離によって追撃の成否が変わります。
カットインの長さはソース上の設定で、実機の表示時間・無敵を保証するものではありません。
