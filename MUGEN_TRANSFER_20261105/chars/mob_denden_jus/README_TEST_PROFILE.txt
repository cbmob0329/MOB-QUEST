【今回の変更】
・地上通常3段は前進開始を早め、前方の相手との距離に応じて前進します。
  電撃3連パンチの前進も増やしました。瞬間移動・必中・判定拡大ではありません。
・通常攻撃の命中時気力150→180、無料スキルと成功カウンター200→240。
  ガード時は通常25／スキル40のまま。スキルは1回の技につき最初の接触だけで、
  先にガードされた後の命中で二重に増えません。投げ90、超技の獲得0、消費量は従来どおり。
・低い姿勢のローキック5枚と、空中ドロップキック5枚を新しく描いて組み込みました。
  ローキックは全20tick、接触7～9tick。ドロップキックは全22tick、接触5～7tickです。
・ドロップキック開始時だけ向いている方向へ横速度3.2を与え、既にそれ以上の
  前進速度がある場合は維持します。相手への追尾や上昇追加ではありません。
  空中時間が残れば約70座標単位進み得ますが、壁・接触・着地で変わります。
  足が先に床へ届く準備／回復姿勢では早めに着地へ移ります。空中停止やジャンプ回復はありません。
・両キックの新しい操作は人操作のみです。AIに新しい選択ルートは加えていません。
  空中の共有4回制限・1回の接触につき1回のダメージ／気力を維持しています。
  相手の体格・距離・移動により外れます。空中連係の必中は保証しません。

【操作：MUGEN内の論理ボタン名】
a / b / c / x / y / z はキーボードの実キー名ではありません。
実際のキー・パッド割り当ては、お使いの MUGEN の入力設定で確認してください。
前・後ろはキャラクターの向きに対する方向です。

移動             前／後ろ
ジャンプ         上（空中でもう一度入力すると二段ジャンプ）
前ダッシュ       前、前
後ろステップ     後ろ、後ろ
通常攻撃         a（地上は命中またはガード後に追加入力で3段）

                 ここで連係終了。通常1段目には戻りません。
ドロップキック   操作可能な空中で 前 + a
                 または空中パンチ1～3段目の命中後、aを離して前+aを押し直す
                 4段目・ドロップキックから次の連係には進みません。

下 + b           1ゲージ：Trick-the-Denden / 大きなシャボンの超技
下 + c           1ゲージ：パンチ超技。初段が当たれば連撃へ。
                 初段が空振り・ガード等で成立しなければ短い回復動作へ。
下 + x           2ゲージ：Denden Thunderbolt
下 + y           2ゲージ：Grand SOAP / 3回放出の大型シャボン超技

超技はしゃがみ・空中からも入力できますが、必要ゲージと操作可能状態が必要です。
低いジャンプでは途中で着地します。空中で止まり続ける演出ではありません。
通常攻撃・無料スキルには気力獲得があります。空振り連打による気力増加や
AIだけの開始ゲージ追加はありません。技には個別の再使用待ちがあります。
空中の c 単独クロス射撃は、この候補では使用できません。
