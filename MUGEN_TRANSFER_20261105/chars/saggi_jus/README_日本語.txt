【導入】
フォルダ名 saggi_jus / DEF saggi_jus.def。
既存フォルダを退避し、このフォルダを丸ごと配置してください。
select.def の [Characters] に saggi_jus を追加します。
キャラ専用ファイルと必要な common1.cns を同梱。ホストの data/common、
select.def 全体を上書きしないでください。MUGEN標準の共通音・ガードスパーク
等はホスト側を利用します。主対象は1対1、AI観戦対戦です。

【簡単入力 / 技一覧】
F=相手方向 B=後ろ D=下 U=上。方向＋ボタンは方向を保持して押します。
x/y/z/a/b/c はMUGEN論理ボタン。実際のキーはホスト設定に従います。
x / y / z：立ち・しゃがみ・空中通常。各同ボタンで命中後3段。
F+x：無料・紫ウイルス弾（飛び道具）
F+y：無料・ワープ（地上/空中、最大3回連続）
F+z：無料・地を進む毒煙（浮かせ、命中後の遅いジャンプキャンセル）
B+y：無料・偽身の罠（設置して後退、近づいた相手を攻撃）
a：1000消費・遠距離魔力弾/ビーム
b：1000消費・近距離命中から包囲連撃
c：2000消費・大型紫ウイルス爆弾
D+c：2000消費・近距離命中から悪夢の分身連撃
x+y：地上投げ / 受け身可能時は受け身
F,F：前進ダッシュ / B,B：後退 / U：ジャンプ
空中でUを離して再度U：追加ジャンプ1回。
技名は挙動の説明です。通常3段は命中と受付時間が必要です。

【今回の統合】
・ワープ3回、最後の使用開始から90tickで回数回復。復帰20tick。
  消失/回避は従来どおり7～9tickのみ。出発点と到着点の演出を分離。
・AIは4無料技＋1ゲージ2技＋2ゲージ2技を距離/高さ/残量/既存Helperで選択。
  強い有料魔法を無料攻撃より優先。無駄な遠距離空振りを減らす射程条件。
  防御は既存ワープ/有限後退を選択。自動ガード成功は保証しません。
・立ち通常9状態の接触前の小前進を維持。通常27状態は各実攻撃段の最初の命中120、ガード40。
  無料魔法は1発動の最初の接触120/40。ウイルス弾の直撃と着弾後で二重加算しない。
  偽身の罠は独立した既存発動番号を使用。空振り/移動0、通常投げ80は既存処理を維持。
・紫ウイルス弾の地上詠唱と毒煙の足元登録を補正。絵は描き直さず、
  対応する当たり判定と弾の発生位置も整合。ウイルス超必殺の演出は維持。
・通常の既存6キー、全超必殺の絵/音/ダメージ、簡単操作を維持。
