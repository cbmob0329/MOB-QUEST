【登録】
フォルダ名: harpy_normal_jus
DEF名: harpy_normal_jus.def

既存フォルダを別の場所に退避してから、同名フォルダを丸ごと入れ替えてください。

【入力】
F=相手方向、B=後ろ、D=下、U=上、DF=下前。方向＋は方向保持とボタン押下です。
x/y/z/a/b/cはMUGENの論理ボタンで、実際のキーはホスト設定に従います。
通常: x / y / z（立ち・しゃがみ・空中、各同ボタン3段）
無料4技: 地上F+x / 空中D+y / 地上D+c / 地上B+y
1ゲージ技（各1000）: 地上a / 地上b
2ゲージ技（各2000）: 地上D+a / 地上D+b
通常投げ: F+c / B+c
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U、空中で離して再度Uで追加1回。
通常連撃は命中・受付時間などの条件があります。押しっぱなしでの自動3連ではありません。

【キャラ固有の注意】
通常連撃は離して押し直し、命中確認時のみ継続します。先端当てや遅い追加入力では次段が外れる場合があります。
通常最終段から技を出せても、長いカットインのある超必殺が必ず連続ヒットするわけではありません。
待機・一部動作は既存の意味が合う姿勢を共有しています。通常版と漫画版は別の選択枠です。
S3はD+cです（旧試作のD+yではありません）。D+F+c / D+B+cも地上ではS3を優先。
空中D+cではS3も投げも出ません。空中D+yは1滞空1回、B+yは60tick再使用待ち。

【共通の注意】
通常攻撃は各段の命中90・ガード20。3段すべて命中なら合計270。
無料必殺技は命中80・ガード20を基準に、1発動の合計獲得上限240。移動のみ・空振りは獲得なし。
超必殺は開始時にゲージを消費し、命中による自己ゲージ獲得はありません。
浮かせ後の追撃には共有上限があり、攻撃側の着地や技の切替だけでは回復しません。
相手の体格・重力・距離によって追撃の成否が変わります。
カットインの長さはソース上の設定で、実機の表示時間・無敵を保証するものではありません。
