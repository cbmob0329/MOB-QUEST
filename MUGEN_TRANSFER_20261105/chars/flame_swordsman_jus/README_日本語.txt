炎の剣士 — Production v2 統合版（2026-10-26）

全キャラデータを含む差し替え用フォルダです。差分パッチではありません。
静的ソース・実際のSFF/AIR画像・依存ファイルを確認していますが、MUGEN/IKEMENの起動・入力・対戦・音声再生は未確認です。「全技を実機で完成確認済み」という意味ではありません。
基本対象は1対1。同時チーム戦や外部キャラ全般への互換性は保証していません。

【導入】
1. 現在の flame_swordsman_jus フォルダを別の場所へ退避。
2. 同名フォルダを丸ごと chars に配置。古いファイルとの混在を避けます。
3. select.def の [Characters] に flame_swordsman_jus を登録。
フォルダ名とDEF名は flame_swordsman_jus / flame_swordsman_jus.def です。
今回は受領済みの common1.cns をキャラ内に同梱。DEFの stcommon = common1.cns はこのローカルファイルを参照します。ホストの data/common や select.def 全体を上書きしないでください。
ホスト標準の共通音・ヒットスパークは引き続き使用します。

【入力】
F=相手方向、B=後ろ、D=下、U=上。方向＋ボタンは方向保持とボタン押下。
x/y/z/a/b/c はMUGENの論理ボタンです。キーボード等の割り当てはホスト設定に従います。
通常: x / y / z（立ち・しゃがみ・空中、各同ボタン3段）
無料4技: F+x / F+z / F+y / B+y
1ゲージ技（各1000）: a / b
2ゲージ技（各2000）: c / D+c
通常投げ: B+z
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U。空中で離して再度Uで追加1回。
F+x は地上・低空、D+c は地上導入・空中に対応します。

通常連撃は新しい同ボタン押下を受付窓で読む方式。押しっぱなしでの自動3連ではありません。
立ち通常の人操作連係には空振りからの受付もあります。AIの次段選択は命中確認条件を維持しています。
無料攻撃の獲得は命中80・ガード20を基準に、1発動合計240が上限。空振り・移動だけでは獲得しません。
超必殺は開始時にゲージ消費し、命中による自己ゲージ獲得はありません。
浮かせ追撃の共有上限・対象ID確認・追加ジャンプ・既存投げは変更していません。

【今回の見どころ】
・立ち x/y/z の全9 Actionを6表示要素化。元の命中絵に、両手剣の溜め・振り抜き・戻し・構え直しを接続。
・新規絵は攻撃12姿勢＋歩行4姿勢。全9技への再利用や6要素の歩行ループを「別々の新作絵」とは数えていません。
・近距離・壁・接触で止まる短い踏み込み。瞬間移動や位置の強制変更ではありません。
・通常の追加炎は実際の命中時のみ。ガード・空振りでは追加の命中炎は出しません。
・c の上昇斬りと着地炎柱は保持。着地炎柱の実際の命中時だけ大きい炎の余韻と有限の画面揺れを追加。
・既存の待機6姿勢、c始動3姿勢／地上復帰2姿勢、全旧絵・入力・消費・HitDefを保持。

c は上昇攻撃→実際に着地した炎柱→復帰です。始動命中で相手を捕獲する新しい専用演出ではなく、炎柱自体が独立した実体判定を持つ既存技です。空振り時にも元の技本体の炎は表示されます。
新規アーマー、無敵、敵の強制State、追加ダメージ判定は導入していません。
