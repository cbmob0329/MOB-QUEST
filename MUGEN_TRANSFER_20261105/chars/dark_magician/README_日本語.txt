ブラック・マジシャン 操作と導入

このフォルダにはブラック・マジシャン1体分の全必須データを収録しています。実機の起動・入力・対戦・音声再生は未確認です。
基本対象は1対1です。外部キャラや同時チーム戦での動作は保証していません。

【登録】
フォルダ名: dark_magician
DEF名: dark_magician.def
select.defの[Characters]に「dark_magician」を1行追加します。
既存フォルダを別の場所に退避してから、同名フォルダを丸ごと入れ替えてください。

【入力】
F=相手方向、B=後ろ、D=下、U=上、DF=下前。方向＋は方向保持とボタン押下です。
x/y/z/a/b/cはMUGENの論理ボタンで、実際のキーはホスト設定に従います。
通常: x / y / z（立ち・しゃがみ・空中、各同ボタン3段）
無料4技: F+x 黒魔弾 / F+z 地這い魔力 / B+y 障壁 / F+y 転移
1ゲージ技（各1000）: a / b
2ゲージ技（各2000）: c / D+c
通常投げ: x+y
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U、空中で離して再度Uで追加1回。
通常連撃は命中・受付時間などの条件があります。押しっぱなしでの自動3連ではありません。

【キャラ固有の注意】
障壁は正面の対応する通常・必殺飛び道具属性への1回防御です。
近接・投げ・背後・超必殺飛び道具を防ぐ万能防御ではなく、外部Helper弾が残る場合があります。

【共通の注意】
通常技は各実攻撃段につき最初の命中120・ガード40。無料の黒魔弾/地這い魔力は1発動の最初の接触で120/40、空振り0。通常3連撃は3段それぞれの実命中が必要。障壁による実弾防御20、通常投げ80は固有の既存処理を維持。
超必殺は開始時にゲージを消費し、命中による自己ゲージ獲得はありません。
浮かせ後の追撃には共有上限があり、攻撃側の着地や技の切替だけでは回復しません。
相手の体格・重力・距離によって追撃の成否が変わります。
カットインの長さはソース上の設定で、実機の表示時間・無敵を保証するものではありません。

【同梱データ】
dark_magician.air, dark_magician.cmd, dark_magician.cns, dark_magician.def, dark_magician.sff, dark_magician.snd
提供済み原本の common1.cns をキャラ内へ同梱しています。ホスト側の共通ファイルは上書きしません。
ホスト標準の共通音・ヒットスパーク等も使用します。ホストのdata/commonやselect.def全体を上書きしないでください。
実機エラー時はエラー全文、MUGEN等の種類と版、配置階層、使用キャラ名を確認してください。

通常の非中断命中は初弾20＋追撃20×6＋最終爆発80＝計8回・基礎総ダメージ220。
既存の1技分220を8倍にはしていません。防御等の倍率で実ダメージは変化します。
初弾と途中6回はKOさせず、8回目の爆発のみKO可能。ガード時は10削り、ガードKOなし。
実際の初弾命中が確認された相手1体だけを有限時間拘束。空振り・ガードでは専用拘束や大爆発へ移りません。
術者中断／KO・対象喪失・ラウンド終了等では途中終了するため、その場合に8回を保証する意味ではありません。

今回の新規身体差し替えはブラックマジックの一連の動作が対象です。
