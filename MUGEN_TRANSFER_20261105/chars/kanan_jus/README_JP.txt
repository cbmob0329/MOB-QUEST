女剣士カナン JUS / MUGEN 1.1 / v1.2並行更新 フル版（確認範囲は試験記録参照）

導入
kanan_jusフォルダをcharsへ配置し、data/select.defの[Characters]へ以下を追加。
kanan_jus/kanan_jus.def
同名フォルダがある場合は先にバックアップ。元ゲーム設定はこのZIPによって自動変更されない。

通常必殺4つ・超必殺3つ
フラッシュスラスト: ↓↘→+a/x または a+c / x+z / 気力消費なし
トリプルエッジ: ↓↙←+a/x または b+c / y+z / 気力消費なし
ライジングセイバー: ↓↘→+b/y または a+b / x+y / 気力消費なし
サイドステップクロス: ↓↙←+b/y または 下+a+b / x+y / 気力消費なし
セイバーダンス: ↓↘→+c/z または 下+a+b+c / x+y+z / 1000消費
疾風一閃: ↓↙←+c/z または 前+a+b+c / x+y+z / 1000消費
天翔連斬: 方向を押さず a+b+c / x+y+z / 2000消費

通常技・通常必殺は1回の技につき最初の命中で120、最初のガードで40。空振り0。多段の再加算と超必殺の自己回収を抑止。2対2の対象別加算は未検証。
通常技a→b→cは命中・ガードから連係。しゃがみa/b、空中a/b、前後ダッシュ、標準ジャンプ・二段ジャンプ。
ボタンはMUGEN表記。キーボードの割当は本体設定に従う。

高速の歩行・短い剣の予備動作・踏み込み連斬を持つ剣士。カオスのアーマーは持たない。

追加超必殺は既存作業版の独立コマを使用。被投げ用の軸違い画像は新規作画に数えない。
小さい選択アイコンと大ポートレートは同梱本体画像から作成。SFF2.01のPNG8、透明パレット、AIR参照、必須被投げ番号を検査。

実機確認範囲と未確認はTEST_RESULTS_JP.txtを参照。全相手・全独自技との互換やGokuと同等品質の認定を意味しない。
