【入力】
F=相手方向、B=後ろ、D=下、U=上。方向＋は方向保持とボタン押下です。
x/y/z/a/b/cはMUGENの論理ボタンで、実際のキーはホスト設定に従います。
通常: a / b / c。立ち・しゃがみ・空中に同ボタン3段のルートがあります。
無料4技: F+a / F+b / D+c / 空中D+a
1ゲージ技（各1000）: x / y
2ゲージ技（各2000）: 地上D+z / 空中D+z
従来の同時押し: a+b=地上1ゲージ、b+c=地上1ゲージ、D+a+b=地上／空中2ゲージ。
通常投げ: a+c
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U。空中で離して再度Uで追加1回。

通常連撃は命中・受付時間・再入力等の条件があり、押しっぱなしの自動3連ではありません。

通常ボタンはa/b/cです。x+yを通常連撃用と取り違えないでください。
