キョロゾー 操作と導入

全キャラデータを含む更新版です。実機の起動・入力・対戦・音声再生は未確認です。
基本対象は1対1です。外部キャラや同時チーム戦での動作は保証していません。

【登録】
フォルダ名: kyoro_ember
DEF名: kyoro_ember.def
select.defの[Characters]に「kyoro_ember」を1行追加します。
既存フォルダを別の場所に退避してから、同名フォルダを丸ごと入れ替えてください。

【入力】
F=相手方向、B=後ろ、D=下、U=上、DF=下前。方向＋は方向保持とボタン押下です。
x/y/z/a/b/cはMUGENの論理ボタンで、実際のキーはホスト設定に従います。
通常: x / y / z（立ち・しゃがみ・空中、各同ボタン3段）
無料4技: a / D+a / F+a / B+a
1ゲージ技（各1000）: b / D+b
2ゲージ技（各2000）: c / D+c
通常投げ: x+a
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U、空中で離して再度Uで追加1回。
通常連撃は命中・受付時間などの条件があります。押しっぱなしでの自動3連ではありません。

【キャラ固有の注意】
8技は地上始動。方向なしaと方向付きaを使い分けます。下方向は斜め入力でも優先します。
短い準備中の一部アーマーは被ダメージありの1回受付です。実機の被ダメージ・復帰順は未確認。
連射は片掌と両掌の姿勢を使い、左右交互の新規作画ではありません。

【共通の注意】
無料攻撃は命中80・ガード20を基準に、1発動の合計獲得上限240。移動のみ・空振りは獲得なし。
超必殺は開始時にゲージを消費し、命中による自己ゲージ獲得はありません。
浮かせ後の追撃には共有上限があり、攻撃側の着地や技の切替だけでは回復しません。
相手の体格・重力・距離によって追撃の成否が変わります。
カットインの長さはソース上の設定で、実機の表示時間・無敵を保証するものではありません。

【同梱データ】
ember.air, ember.cmd, ember.cns, ember.sff, ember.snd, kyoro_ember.def
標準 data/common1.cns はホスト側のものを使用します。
ホスト標準の共通音・ヒットスパーク等も使用します。ホストのdata/commonやselect.def全体を上書きしないでください。
実機エラー時はエラー全文、MUGEN等の種類と版、配置階層、使用キャラ名を確認してください。
