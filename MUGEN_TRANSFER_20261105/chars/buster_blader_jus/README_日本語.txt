【入力：変更なし】
F=相手方向、B=後ろ、D=下、U=上。方向＋は方向保持とボタン押下です。
x/y/z/a/b/cはMUGENの論理ボタン。実際のキーはホスト設定に従います。
通常: x / y / z（立ち・しゃがみ・空中、各同ボタン3段）
無料4技: F+x / F+z / F+y / B+y
1ゲージ技: a / b（各1000消費）
2ゲージ技: c / D+c（各2000消費）
通常投げ: B+z
受け身: x+y（受け身可能時）
前進ダッシュ: F,F / 後退: B,B
ジャンプ: U、空中で離して再度Uで追加1回。
連撃・追撃は受付時間や相手状況に制約があり、押しっぱなしの自動連続攻撃ではありません。
