サクリファイス JUS v1.2 更新（2026-10-26）
各ボタンで3連撃：a-a-a / b-b-b / c-c-c、x-x-x / y-y-y / z-z-z。
立ち・しゃがみ・空中に対応。追加押しを先行受付し、命中またはガード接触から次段へ繋ぐ。1回押しだけでは自動で3段を出さない。空振りからは連撃キャンセルしない。
1・2発目は相手を途中で倒さず、3発目で基本ダウン。地上a→b→cの混合入力も残す。
眼ビームも3段化。空中ビームは発射時の相手の胴へ角度を合わせ、空中射撃の落下速度を少し抑える。
通常時の3発合計150ダメージを専用ダミーで確認（吸収強化・相手防御値などで変動）。
既存の作画を連撃に再構成した更新で、新しい絵を増やしたと数えていない。
原作資料に基づく横長カットインも同梱。表示・スライドは実機確認。通常の停止時間は54tick（確認用600tickは製品に含まない）。
クローン吸収・HP・20％軽減・破壊反動・カウンター・必殺4／超必殺3・二段ジャンプは保持。
ゲームが旧版を読み込み済みの場合は再起動してこの版を読み込んでください。

以下は従来の操作・仕様（通常攻撃は上記v1.2が優先）：
サクリファイス JUS v1.1 フル版 / MUGEN 1.1

導入
ZIPを展開し、relinquished_jusフォルダをMUGENのcharsへ入れてください。
data/select.defの[Characters]に次の行を追加すると選択できます。
relinquished_jus/relinquished_jus.def
既存の同名キャラがある場合は先にバックアップしてください。
DEF・CNS・CMD・AIR・SFF・SND・common1.cns・soul.cnsをすべて含む独立版です。

操作（MUGENのボタン名。キーボード配置は本体設定によります）
a/x：爪、b/y：打ち上げ、c/z：眼ビーム
下を保持してa/b：低姿勢攻撃、空中a/b：空中攻撃
→→：滑空ダッシュ、←←：後方回避、空中で上：二段ジャンプ
↓↘→+a/x または a+c / x+z：強化眼ビーム（消費なし）
↓↙←+a/x または b+c / y+z：爪突進
↓↘→+a+b / x+y または a+b+c / x+y+z：吸収超必殺（1000ゲージ）
追加操作
↓↘→+b/y または 下+a+c / x+z：吸引波（命中で引き寄せ、消費なし）
↓↙←+b/y または a+b / x+y：ミレニアム・カウンター（消費なし）
カウンターは3フレームの構え後12フレーム受付。接触打撃を取り、投げ・飛び道具は取らない。
空振りは23フレームの戻り動作。成功時のみ眼ビーム反撃。
↓↘→+c/z または 下+a+b+c / x+y+z：眼光六連射（1000ゲージ）
↓↙←+c/z または 後ろ+a+b+c / x+y+z：アビス・ノヴァ（2000ゲージ）
通常必殺は強化眼ビーム・爪突進・吸引波・カウンターの4つ。
超必殺は吸収・眼光六連射・アビスノヴァの3つ。
通常必殺は命中時45ゲージ増加。ガード時は爪突進10、他15。空振りでは加算しない。
通常a→b→c、低a→b、空中a→bの命中連係を実装。
本環境のキーボードではa,b,cがq,w,eに対応。別環境では設定に従ってください。

吸収
共通の影を腹部へ取り込みます。相手キャラそのものの画像複製は行いません。
クローンHP300。生存中は攻撃ダメージ20%上昇、標準HitDefの被ダメージ20%軽減。
本体の確定被ダメージをクローンHPにも反映。破壊で強化と軽減を解除します。
破壊時は吸収元の相手へ最大HP20%を一度だけ与えます。相手の無敵中は接触可能になるまで待機します。

画像と演出
実装済みの本体72ポーズ、ビーム・吸収波・爪・被弾等のエフェクト、合成効果音を同梱。
目や首の伸長演出はありません。固定の本体縮尺で、状態切替時の原寸表示を防ぎます。
選択用小アイコンと大ポートレートは実装済み画像から作成。
162スプライトのうち標準被投げ用の軸違い参照は互換用であり、新モーション数には含めません。

互換性と確認範囲
MUGEN 1.1で検証。WinMUGEN/MUGEN 1.0対応版ではありません。
相手がHPを直接変更する独自投げ・防御無視技では20%軽減を保証しません。
整数処理により小ダメージには端数差が出ます。永続無敵・特殊な被弾拒否・Simul全組合せは未検証。
詳しい実機結果はTEST_RESULTS_JP.txtを参照してください。
GokuSSBと同等の作画密度・技数を保証するものではありません。
