MOB PIECE BATTLE フィギュア能力・タグ・ルビー仕様 v2（v115実装値）

【基本】
・モブピースの個体ステータスは HP / ATK / DEF / SPD の4項目。
・HP＝LIFE。同じ意味なので表示・戦闘計算はHPに統一。HPが0になったフィギュアはKO。
・レア度差は存在するが、タグ構築のバフ・デバフが勝敗の中心。
・センターは従来どおり全ステータス+25%。

【レア度の基準帯】
R    HP75～90 / ATK+DEF+SPD 合計56前後
SR   HP88～105 / 合計64前後
SSR  HP102～120 / 合計74前後
UR   HP118～138 / 合計86前後
MOB  HP138～160 / 合計100前後

【ガチャ所持上限 / 超過ルビー】
R：9体 / 超過時 RUBY +1
SR：6体 / 超過時 RUBY +2
SSR：4体 / 超過時 RUBY +5
UR：2体 / 超過時 RUBY +15
MOB：1体 / 超過時 RUBY +50

【ルビー交換必要数】
R 10 / SR 50 / SSR 100 / UR 300 / MOB 500
・選択中ガチャのラインナップから交換。
・交換前に確認必須。
・所持上限到達済みは交換不可・ルビー消費なし。

【デッキ同種上限】
R・SR：同じフィギュアIDを3体まで
SSR・UR：同じフィギュアIDを2体まで
MOB：同じフィギュアIDを1体まで
・同じキャラクター名でも別フィギュアIDなら別種類。
・完全に同じフィギュアを複数入れてもタグ人数は1種類分しか数えない。

【タグ重複上限】
HP +60% / ATK +60% / DEF +60% / SPD +50%
相手ATK -40% / 相手DEF -40% / 相手SPD -35%
センター HP・ATK・DEF・SPD 各 +60%
