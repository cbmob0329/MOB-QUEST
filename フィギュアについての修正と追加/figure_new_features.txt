フィギュアの新要素

・1種1体しか所持できない
重複は+9まで自動的に重ねられて、それ以降はルビーに変換される
+1につき、ステータス効果+1
例:
+値でatk+5→+値9なら+14

・棚に飾る
メイン画面の左上にフィギュアを飾るボタンを追加する
※フィギュアが購入できる状態になるのと同時に行う

今は背景がほぼ何もない状態です
所持フィギュアを
上から MOB 1個　UR 3個 SSR 5個 SR 7個 R 12個
以上のフィギュアを展示することが可能です
枠など一切なしでフィギュアそのものを飾ることが出来ます
※上記の数字の通り、全部飾ればピラミッドが出来上がります

数は最大値なので、例えばMOB 1個 UR 1個 SSR 3個 R 3個 のみ展示などもできます。
形はいびつになると思いますが、出来る限り整えてください。

ステータス効果は合計の30%のみパーティー全員に反映
特性も30%のみ反映
※その数値が1以下になる場合は0となります。
例、ダメージ軽減3％→30%は0.9%なので、0となる

・サブフィギュア
1キャラにつき、さらにフィギュアを4体装備出来るようにします
ただし、全効果が30%になります。
1以下になる場合は0となります。
例、ダメージ軽減3％→30%は0.9%なので、0となる

・出番が来た時、キャラクターの上に装備しているメインフィギュアを並べて表示する
※そのキャラクターが装備しているメインフィギュアのみ表示する
フィギュアのバランス、戦闘画面のバランスを考えて表示してください
戦闘画面は現状を維持したいです
サブフィギュアは表示しないでください

・SOULとフィギュアスキル

SOUL について
0からCTを開始し、タグ効果によって　戦闘開始時のSOUL値が変わる
SOULが溜まったらフィギュアが溜まり、タップするとフィギュア必殺技を発動
フィギュア必殺技はターンを消費しない

SOULはターン経過で溜まる
ただし、戦闘によるリセット無し
※例えば必殺技発生に必要なSOULが6の場合、タグ効果により3 SOUL溜まるとしたらあと3ターンで必殺技を打つことが出来る
これを戦闘中に使わなかったとしてもSOULはまた0となる
戦闘が始まったらタグ効果でまた3 SOULになる

モブピースバトルに置いてのSOUL
溜まり方は1タグ(隣接タグではなく、通常のタグ)につき1SOUL溜まる
1ターンでフィギュアは場を離れるため、ターン経過によるSOUL増加は無い
1 SOUL 5 SOUL 10 SOUL の3パターン威力効果がある
モブピースバトルでは、必殺技を1ターンに2体しか発動出来ない

共通
SOULが溜まるとフィギュアが光る
タップすると効果と発動するかの確認→必殺技発動
通常の必殺技効果とモブピースバトル用の効果がある

発動効果
そのフィギュアがカットインし、フィギュアスキル発動!!とアメコミ風にかっこよく表示
その後、攻撃の時はフィギュア型に敵に刻印エフェクト→爆発
バフ効果の場合はフィギュア型に緑の点滅とバフの効果を表示


■モブピースバトルについて
どのランクでも、登場していないガチャのモンスターは出てこないようにしてください。

============================================================
■ 未決定部分の確定仕様（今回追記）
============================================================
1) +値
・同一フィギュアは1種1体所持。重複は+9まで自動合成、+9以降はルビー変換。
・+1ごとに「ステータス効果」に書かれた各ステータスへ+1する。複数ステータスなら各項目すべて+1。
・特性、SOULコスト、フィギュアスキル威力、モブピース効果は+値では上昇しない。

2) メイン/サブ/棚
・メインフィギュア: ステータス効果・特性100%。原則SOULとフィギュアスキルを持つ。ただし超合金フィギュアは例外で、SOUL/フィギュアスキルを持たない。
・サブフィギュア4枠: ステータス効果・特性30%。アクティブスキル/SOULは発生しない。戦闘画面にも表示しない。
・棚: 展示中フィギュアのステータス効果・特性の合計30%をパーティー全員へ反映。アクティブスキル/SOULは発生しない。
・30%換算: まず元数値（+値反映後）×0.3を計算し、その生値が1以下なら0。1を超える場合は小数点以下を切り捨てる。例:+3→0、+5→1、+10→3。
・同じフィギュアを棚と装備へ同時使用することは不可。展示中を装備する場合は棚から自動解除し、逆も同様。
・サブフィギュアと棚のフィギュアは隣接タグ判定に参加しない。プレイヤー装備の隣接タグは既存のメイン4枠A-B/B-C/C-Dだけで判定する。
・棚は同じ効果項目をいったん合計してから30%換算する。サブは1体ごとに30%換算してから合算する。
・+9到達後の重複ルビー変換は R=1 / SR=3 / SSR=8 / UR=20 / MOB=50 とする。イベント・超合金もレア度基準で同じ。

3) 通常戦闘のSOUL
・戦闘開始時SOUL = 発動中のタグ効果で得る開始SOULの合計。該当効果が無ければ0。
・各メインフィギュアは自分の行動キャラクターのターン終了ごとにSOUL+1。
・敵の増援/ウェーブ移行ではSOULをリセットしない。
・フィギュアスキル発動時、対象フィギュアのSOULを0にして再蓄積する。フィギュアスキルはターンを消費しない。
・戦闘終了時はSOULを持ち越さず0。次戦闘は再びタグ効果による開始SOULから始める。
・SOULがコスト以上なら発光。タップ→効果確認→発動。

4) モブピースバトルのSOUL
・隣接タグではなく、そのフィギュア自身の通常タグ数をSOUL値とする。上限10。
・1～4SOUL = 「1」の効果、5～9SOUL = 「5」の効果、10SOUL = 「10」の効果。
・場に出た1ターン中はターン経過SOUL加算なし。
・1ターンにフィギュアスキルを発動できるのは最大2体。3体以上発動可能な場合はプレイヤーが2体を選ぶ。
・モブピース側のフィギュアスキルも行動/配置ターンを追加消費しない。
・モブピースバトルでは、バトル開始後のHP/LIFE回復・自動回復・蘇生は発生しない。
・HP/LIFE+○%は最大HP/LIFEへの戦闘開始時補正であり、失ったHPを戻す回復効果ではない。
・必要SOUL/消費SOULを減らす効果は使用しない。SOUL操作は獲得SOUL増加、または敵への獲得SOUL減少デバフとして扱う。

5) スキル設計基準
・新規SOULコスト基本値: R=5 / SR=6 / SSR=7 / UR=8 / MOB=9。既存の決定済みコストは変更しない。
・モブピース新規基本値: 単体HPダウン 5/8/12%、全体HPダウン 3/5/8%、単一ステータス強化 5/10/15%、2種同時強化 3/6/9%。
・MOBランクは一部のみ上限を少し高くし、最上位感を出す。

6) モブピースバトルの能力表記
・モブピースバトル内でフィギュアスキルが直接上下させる能力は HP / ATK / DEF / SPD を使用する。
・RPG側の MAG / MND / MP はモブピースバトル用スキル効果には直接使用しない。
・隣接タグの詳細効果は「フィギュアの隣接タグについて_修正版.txt」を正とする。


■フィギュアスキル名称・効果の設計ルール（名称短縮・統一版）

・スキル名にキャラクター名、フィギュア名、シリーズ内の固有キャラクター名を入れない。
・「キャラクター名＋技名」「技名＋初太刀/連撃/奥義」など、名前を長くするだけの接頭語・段階名は使わない。
・技名は短く、効果・属性・動きが連想できる名称を優先する。
・同じフィギュアの通常戦闘用スキルとモブピースSOUL1/5/10は、同じ技名を使用する。段階差は効果内容と数値で表現する。
・キャラクターの属性、通常タグ、特性、登場シリーズは「名前を入れるため」ではなく、技の方向性を決める材料として使う。
・同シリーズでも役割を分ける。
  例: 攻撃 / 防御 / 回復（通常RPGのみ） / SPD操作 / デバフ / MP補助 / CT補助など。
・モブピースバトル用スキルも、全員を「敵HP○%ダウン」だけにはしない。
  ATK / DEF / SPD / HP、センター強化、全体強化、敵デバフなどをキャラクターごとに使い分ける。
・SOUL1 / SOUL5 / SOUL10は数値だけを上げるのではなく、上位段階で副効果が追加されるフィギュアを作る。
・超合金フィギュアはSOUL/フィギュアスキルを持たない。ステータス効果・特性・通常タグで個性を出す。
・既存のスキル効果は今回変更しない。名称のみ上記ルールへ統一する。

【スキル名称の正式ルール】
・キャラクター名をそのまま先頭に付けた「○○・技名」形式は禁止。
・短く、口に出しやすく、見ただけで元キャラを連想できる名前を優先する。
・造語・言葉遊び可。例: ロックパンチ / スラスライダー / カネノオト / イワサンダー。
・SOUL1/5/10で技名は変えず、数値と追加効果だけを強化する。
・超合金フィギュアはスキルを持たない。
