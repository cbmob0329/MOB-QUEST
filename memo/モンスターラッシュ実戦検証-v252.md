# ラッシュの実戦闘エンジン検証

## 方法

手動プレイではなく、隔離したPlaywright/Edgeの一時ブラウザーで実際のゲーム戦闘エンジンを動かした自動操作試験です。実ユーザーのブラウザー・セーブには接続していません。
`tests/rush-balance-v252.cjs` で再実行できます。初期状態・装備・MPを毎回リセットし、4クエスト×推奨Lv.−3／推奨Lv.／＋3×乱数シード25201・25202・25203の36試行を順番に実行しました。

待機時間、会話、描画・画像先読み・攻撃エフェクトを省略しています。ダメージ計算、命中、耐性、敵のAI・パッシブ、ターン進行、状態異常、必殺技CT、味方パッシブ、援護、消費MP、回復量、死亡と交代は元の処理を使っています。敵HPを0にする／味方を回復させる等のテスト専用戦闘補正はありません。
最初の検証プログラムでは非同期の敵行動完了前にループが先行したため、busy解除を待つよう修正してから結果を取り直しました。下記はその修正後の結果です。

## 編成・装備

| 対象 | メイン | 援護 | 武器 |

防具は編成順に「ぷにモブグリーン」「ぷにモブレッド」「ぷにモブピンク」「ぷにモブパープル」「ぷにモブミント」「ぷにモブイエロー」を1個ずつ（2人／4人編成は先頭2／4個のみ）。副武器・メダル・フィギュアなし。アイテム不使用。主人公の終盤追加パッシブとマニーの追加解放能力なし。テストモードの能力補正・全技解放なし。
地域クリア状況は各解放段階に設定し、武器は実際の `blacksmithShopWeapons()` に含まれることを確認しています。草原・田舎町はSEASON1、マグマ・部族村段階はSEASON2です。
防具01～05は草原サブクエスト、06は砂漠サブクエストの報酬。利用可能な地域のサブクエストに実際に報酬が存在することを `SUBQUEST_AREAS` で確認し、同じ報酬を重複取得する前提は避けています。対象のサブクエストを先に攻略した編成です。
武器を全て購入する場合の定価合計は草原1万G、田舎町2万G、後半6人7.3万G。資金・基礎防具を用意した編成であり、地域を初めてクリアした瞬間の所持品の保証ではありません。
初回の仮試行では同じ基本防具を複数人に用意していたため、入手数の監査後に上記の個別防具へ訂正し、36試行を取り直しています。以下の最終結果は個別防具の条件です。

## 自動操作の戦術

各レベルで習得済みの技だけを選びます。

1. 生存メンバーのHPが65%未満なら、使用可能な回復魔法を優先。複数人が減っていれば全体回復・状態異常解除、そうでなければ単体回復。
2. 残りMPから最大18MP程度の回復用予備を確保。攻撃・攻撃魔法・特技の属性、ATK/MAGと敵DEF/MNDを比較して選択。
3. フェニックスには水を優先。使用可能な必殺技は3ターンごとに候補の先頭を使用。
4. 戦闘不能者が出た場合は既存処理で援護メンバーと交代。ピンクの復活対象は先頭の対象を選択。

例えば草原ではネオソード、アノソード、キャンディなど、マグマではネプマ／ネプマソードなどが使用されます。全使用技・対象・行動時MPは生ログの `actions` に記録しています。戦術は単純なヒューリスティックで、最適解の探索や人間の判断の代替ではありません。

## 発見した問題と調整

最初の推奨Lv.試行では草原・田舎町・マグマはクリアしましたが、灼熱はフェニックス戦80ターンで全滅しました。最終HPは敵9669、ニョロやピンクのMPはほぼ尽き、回復の繰り返しになりました。前座の消耗だけでなく、毎ターン500回復・吸収・HP半分で一度全回復・水以外への耐性が長期戦を生む結果です。
短編とSSRメダル1枚の報酬に対して過剰と判断し、**ラッシュ専用データのフェニックスのみHP30%、ATK/MAG75%**にしました。Lv.80では実HP4066、ATK/MAG258です。行動2～3回、耐性・回復・吸収・一度全回復・ターン強化は残しています。元イベントのテンプレート・JS能力処理は変更していません。
一度HP50%で試した際はクリアしてもフェニックスだけ27ターンだったため、短編としてさらにHPを調整しています。最後に変更した30%条件を3段階×3シードで確認しました。
セリフは「今日は力を抑え、連戦の成果を見届けよう」に更新。JSON、初期作成用スクリプト、編集手順、埋め込みゲームデータを一致させました。

他3件と報酬性能は据え置きです。田舎町は4人編成で短く安定する区間、草原は2人・回復習得前だと危険が増す入門、マグマは属性と資源管理、灼熱は元イベント経験者向けの長めの締めという差があります。
短編報酬の実加算はDEF3/HP10、ATK4/MP10、MAG4/MND4、DEF5/HP20。耐性3～5%または防御時軽減5%で、元イベントURの能力や追加報酬を超えません。完了1回限り・途中収入なしの方針も維持しています。

## 証跡・再実行

- `artifacts/rush-v252/balance-results.json`：調整後36試行の全ログ。
- `artifacts/rush-v252/balance-before.json`：調整前の推奨Lv.4件（当初の同一防具を複数人へ用意した仮条件）。上級の80ターン全滅を含む。最終条件と装備が完全同一の対照試験ではありません。
- `artifacts/rush-v252/rush-before-balance.json`：追加検証前のラッシュデータのバックアップ。
- `tests/rush-balance-v252.cjs`：実エンジン自動操作コード。

```powershell
node scripts/build-v252.cjs
node tests/rush-balance-v252.cjs
```

今回の結論は上記装備・編成・戦術と少数の固定乱数に限ります。手動通しプレイ、別編成・裸装備・技の選び方が異なるケース、実端末での操作感、広い乱数分布の統計的勝率は未検証です。

調整後の最終再検証ではラッシュの進行・保存・会話テスト、元イベントとの能力／報酬比較がPASS。既存回帰テスト5本もPASSでした。既存の失敗3本は編集前と同じアサーションで停止しており、新たな失敗理由は出ていません。ただし停止箇所以降の検査はその3本では未実行です。結果は `artifacts/rush-v252/post-balance-verification.json` に記録しています。
