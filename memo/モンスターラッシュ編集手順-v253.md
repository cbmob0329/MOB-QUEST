# モンスターラッシュ v253 編集手順

既存4件に10件を追加した計14件です。旧クエスト・メダルのIDと保存先 `meta.monsterRushV252` は維持しています。旧4件を受領済みのセーブでは受領済みのまま、追加10件だけが新しい報酬対象です。

## 編集元と反映

- **`js/rush-v252.json`**：14件すべての編集元です。クエストID、解放条件、推奨Lv.、AREA、WAVE、敵Lv.、敵テンプレート、台詞、報酬、メダル性能を収録しています。互換のためファイル名・ID末尾のv252を維持しています。
- `js/rush-v252.js`：有限報酬、WAVE、AREA、敗北／中断などの進行処理
- `js/rush-v253.js`：4件ずつのページ一覧、吹き出し、円形メダル、特性重複防止
- `js/rush-validation-v252.js`：ゲーム起動時とビルド時で共通の検証
- `css/rush-v252.css` / `css/rush-v253.css`：表示。新規の金縁・光沢はCSSで描画します

UTF-8でJSONを編集し、MOB-QUESTフォルダで次を実行してください。

```powershell
node scripts/build-v253.cjs
node --check js/game.js
node tests/rush-data-v253.cjs
node tests/rush-v253.cjs
node tests/rush-traits-v253.cjs
node tests/rush-visual-v253.cjs
```

その後 `index.html` を再読み込みします。ゲームはJSONからビルドした埋め込みデータを直接読みます。file://起動との互換性を保つため実行時fetchは使いません。JSONを編集しただけでは画面に反映されません。生成済み `js/game.js` と `index.html` のデータを直接編集すると再ビルドで上書きされるため、編集元を使ってください。

`scripts/build-v252.cjs` も同じ最新版を生成します。`scripts/extend-rush-v253.cjs` は一度だけ使用した移行用で、14件のデータがあると停止します。通常の編集では実行不要です。

## 台詞と吹き出し

`quests[].areas[].pre` / `post` に `{ "speaker": "pink", "text": "次も今のHPとMPで\n進むであります！" }` のように記述します。

- 使用話者は `pink`、`desert`、`denden`、`money`、`nyoro`、`v179-phoenix`。デザートは砂漠、デンデンは田舎町、マニーはネオン街、ニョロはマグマ以降の解放条件で使えます。加入前の地域の台詞に出すと検証で停止します
- **句点「。」は禁止**。文の切れ目は改行か「！」「？」、自然な区切りにしてください
- `\n` ごとに次の吹き出しへ送ります。1行は2〜14文字。助詞や単語を途中で切らず、意味のまとまりで短く書いてください
- ピンクは「であります」、デンデンは「でやんす」、ニョロは「ニョロ」、マニーは既存の女性口調を維持します
- キャラクターの立ち絵を表示し、話者へ向いた矢印付きのゲーム標準吹き出しを使います。長い施設用ダイアログは使いません
- 変更後は320pxなどの狭い画面でも確認してください。検証は句点・長さ・はみ出し・矢印を確認しますが、日本語の自然さは編集者の確認が必要です

## 敵・進行・上限

`areas[].waves` はWAVEの配列、その中は `{enemy,level}` の配列です。1クエスト1〜2 AREA、全体2〜4 WAVE、同時最大2体。通常敵は1行動、中ボスは原則2行動、旧フェニックスは2〜3行動です。各値と技・耐性・固有パッシブは `enemies` に収録しています。

新10件は既存テンプレートをコピーして使い、技・パッシブ・耐性を残しています。メラケロの灯火、ヨーガンスライムの反射、スラミイラの撃破時変身／全回復、ミラバスターの魂、魔女の軽減などは既存の実装が動作します。変身しても同じWAVEを継続し、勝利扱いにはしません。新たな召喚敵は追加していません。

旧フェニックスだけ稽古用 `mods: {hp:0.3,atk:0.75,mag:0.75}` を維持します。元のままでは短編として長すぎた実戦検証に基づく調整です。元イベントの敵テンプレートには適用しません。

WAVE間はHP・MP・状態異常・一時効果・ターンを保持、AREA間はHP・MP・死亡・状態異常を保持します。AREA間に無料回復はありません。敗北／中断／HOME／再読み込み後は未クリアならAREA1から再挑戦です。途中セーブ再開はありません。

## メダルと特性

報酬は各1枚のみ。経験値・コイン・ダイヤ・フィギュア・通常ドロップはなし。最終勝利時にクリア記録とメダルを同じmeta保存へ書き、台詞や結果画面で閉じても二重受領を防ぎます。

`medals[].stats` は武器基準の値で、メダル装備時は**10%**が実加算です。特性の確率や軽減率は10%になりません。`traitLabel` は `traits[].label` を ` / ` で連結した内容と一致させます。表示だけの架空特性は使っていません。

| メダル | 装備時の実加算 | 実際に働く特性 |
|---|---|---|
| サバンナ | DEF3・HP10 | 地耐性3%＋物理軽減2% |
| キャプテン | ATK4・MP10 | 闇耐性5%＋会心率2% |
| フレザード | MAG4・MND4 | 火・水耐性各5% |
| マグゴーレム | DEF5・HP20 | 防御時追加軽減5%＋防御時HP2%回復 |
| ポイズン | ATK2・HP10 | 通常攻撃後3%で毒付与判定 |
| エネチェイサー | SPD3・MP10 | 回避率3% |
| ウェイブ | MND4・MP10 | 水耐性5%＋防御時MP2%回復 |
| メラケロ | MAG4・HP10 | 火魔法の消費MP5%軽減 |
| タフネス | DEF4・HP15 | 防御時HP3%回復 |
| ラプチー | ATK4・SPD2 | 会心率3% |
| ネオタイガー | SPD4・ATK2 | 回避率4% |
| ヨーガンスライム | MND4・HP10 | 物理軽減3%＋火耐性5% |
| ミラバスター | MAG4・MP10 | 闇魔法の消費MP5%軽減＋闇耐性5% |
| キラウィッチ | MAG4・MND4 | 防御時MP3%回復＋闇耐性5% |

毒は通常攻撃後の既存付与処理を使い、相手の状態耐性・生存などの条件に従います。会心・回避は加算後に既存上限が適用され、敵の命中補正も働きます。MP軽減は魔法のみで切り上げ計算のため、小さい消費量では1MPも変わらない場合があります。防御回復は防御行動1回につき最大HP／MPの指定割合、上限まで回復します。低HP自動回復ではありません。

異なるメダルの同種特性は既存ルールで加算・上限処理します。同じラッシュメダルIDを複数スロットに重複させた不正なインポートデータでは特性を1枚分に抑えます。通常の装備UIでは所持数1枚を超えて装備できません。

既存ファイトSSRのATK5・DEF5／低HP軽減5%、マカロンURのATK10／追撃3%、ドラゴンURの火闇耐性各15%と比較し、短編報酬は補助用途に抑えています。特性は1枚最大2個、値は最大5%、毒判定は最大3%。14枚を集めても装備枠制限があり、全効果を一度に装備できません。

## アイコン・円形エフェクト

共通 `mqicon/rush-v252.png` は旧版の生成済みRUSHアイコンを継続使用します。既存 `mqicon/14.png`、`medal/01.png`、`enemy/09.png` を目視参照した透過PNGです。今回のメダルは該当する既存モンスターPNGをCSSの円形金縁・内側の陰影・光沢で包み、MEDAL表示を付けました。一覧、報酬、所持品、装備枠、装備選択に適用します。モンスターの戦闘画像や元PNGは変更していません。動きを減らすOS設定では光沢アニメーションを停止します。

## 検証とバックアップ

`artifacts/rush-v253/backup/` に今回開始時のコード・JSON・CSS・旧手順・旧テストを保存しています。通常セーブを使わず、隔離した一時Edgeでテストします。ゲーム本体の変更は既存ラッシュ用ブロックとそのビルド出力に限定します。他リポジトリ・素材原本・実ユーザーセーブは変更しません。

詳細な実戦条件と最終結果は `memo/モンスターラッシュ検証-v253.md` を参照してください。検証用スクリーンショットと生ログは `artifacts/rush-v253/` に保存します。実端末タッチ、全装備／全編成、複数タブ同時保存は対象外です。
