# MOB STORY 効果音配置一覧 v257

既存のエンディング曲とネオン街演出以外には共通SEがなかったため、SE専用システムを追加しました。BATTLEの `src/audio/synthesis.js` と `audio.js` を読取参照し、STORY内へコピー・調整しています。BATTLEや素材原本は変更していません。BGMの追加はありません。

## 設定

ゲームの「設定」に「効果音（SE）」を追加。音量0～100%、消音、試聴が使用できます。初期値55%。`localStorage` の `mob-story:se:v1` に保存します。ゲームのセーブ、既存メダル3枠・追加2枠、ラッシュの進行データとは別です。設定で明記したとおり、エンディング曲の音量は変更しません。従来のネオン街の小さな演出音は、新しいSE設定に統合しました。

## 音色と負荷対策

- 火＝噴出・破裂、水＝泡、雷＝短い放電、地＝低い衝撃、風＝風切り、光＝高いベル、闇＝低い下降音、無＝中立の打撃。複数属性は重ね合わせます。
- 再利用した合成コードから24kHz・モノラルPCMを必要時だけ生成。最大40音色をキャッシュし、音源ダウンロードは不要です。
- 同時発音は4音まで。低優先のUI音から停止。UI連打は100ms、同じ戦闘音・属性は90ms以内の重複を抑制します。音量調整の後段にコンプレッサーを置きます。
- 1回のSEは最大0.8秒（短いUI音は元の長さ）。早送り時は上限を速度で短縮。SE再生をawaitせず、戦闘の待ち時間を追加しません。
- 最初のタップまたはEnter/SpaceでAudioContextを解放。未対応／音声拒否／保存拒否でもゲームを停止させません。
- 画面移動・HOME・ラッシュ中断・スキップ・非表示・ページ離脱で停止。SE用のsetTimeoutや発音予約キューはありません。再生終了時にノードを切断します。

## 編集手順

1. **配置・条件**：`js/audio/story-v257.js` の該当フックと `seV257('音名', {...})` を編集します。属性は `attribute`、強弱は `strength`（small/medium/large）、長さ上限は `durationLimit`（秒）。ゲーム処理の戻り値・await構造は維持してください。
2. **音色**：`js/audio/synthesis-v257.js`。`CUES`、`cueSpec`、`element`、`synthesizeCue` が音名・時間・属性・波形です。乱数は音声専用で、ゲームの乱数を消費しません。
3. **再生制限・保存**：`js/audio/engine-v257.js`。初期音量、最大発音数、連打間隔、キャッシュ数、保存キーを管理します。
4. **設定UI**：`css/sfx-v257.css` と `renderSoundSettingsV257`。
5. `node scripts/build-v257.cjs` を実行。`js/game.js`、`css/style.css` と埋込版 `index.html` へ反映します。以降の既存build-v254/v256経由でもv257を保持します。
6. `node tests/sfx-v257.cjs` → `node tests/sfx-source-v257.cjs` → `node tests/sfx-browser-v257.cjs` を順番に実行します。

## 確認と限界

`artifacts/sfx-v257/` に検証結果・320/375/390px設定画面・属性試聴WAVがあります。`attribute-audition.wav` の順序は火→水→雷→地→風→光→闇→無です。これは波形検査と試聴用の出力であり、人間が聴取済みという意味ではありません。

ブラウザAudioContextの実再生開始・ノード終了・ゲームイベント接続、音量／消音の再読込保存、PCM振幅・端点・全属性、発音上限、中断停止を自動検証します。実スピーカー／イヤホンでの聴取、iOS Safari実機の初回解放・音量感、全イベント固有演出の通しプレイは未確認です。

変更前バックアップ：`artifacts/sfx-v257/backup/`。既存ユーザーのブラウザセーブは検証に使用していません。commit・push・公開は行いません。

検証実績：SEエンジン・実ブラウザ接続・ソース保持、ミント追加魔法、ラッシュ90難度の敗北／中断／再挑戦／旧セーブ、既存戦闘演出、地域敵／イベント敵／報酬の回帰が成功。検証プログラムでは描画待ちを短縮しています。全編を人が遊んだ検証ではありません。
