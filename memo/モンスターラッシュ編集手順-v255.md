# モンスターラッシュ v255 編集手順・仕様

編集元は引き続き `js/rush-v254.json`（既存ファイルの継続更新）です。実装追加は `js/rush-v255.js`、演出CSSは `css/rush-v255.css`。旧v254の段階別解放・2〜6人検証は履歴です。現行はこの文書を参照してください。

## ビルドと検証

```powershell
node scripts/build-v255.cjs
node tests/rush-v255.cjs
node tests/rush-ui-v255.cjs
node tests/rush-balance-v255.cjs --single
```

ローカルHTMLのためJSONをビルド時に埋め込みます。変更後はビルドして `index.html` を再読み込みます。従来のビルド入口も同じ現行版を生成します。

## 難度・Lv.

ハードは全30件のノーマル制覇、インフェルノは全30件のハード制覇で全体解放。地域・元イベントの条件も維持します。JSONの `difficulties[].unlock` は `region` / `allPreviousTier`、`minLevel` は1 / 50 / 80です。クエストLv.は推奨Lv.+難度加算と下限の高い方。敵も個別Lv.+加算と下限の高い方です。参加キャラクターへのLv.50／80制限はありません。

旧14件の受領済みはノーマル実績へ読み替え、旧v254の難度別実績・最高メダル性能も保持します。ただし旧版で一部ハード／インフェルノをクリアしていても、新しい参加解放条件は全件制覇です。実績を削除したりメダルを弱体化したりしません。

## 専用4人編成

`partyRule` は4人ちょうど、必須1人＋自由3人。各クエストの `requiredCharacter` と `requiredCharacterHelp` で指定・加入案内を編集します。ゲームの `MOB_DATA.players` にあるIDを指定できます。後で変更する場合も、その地域の進行で加入できる仲間を選んでください。現データでは進行内で加入できる勇者・ピンク・デザート・デンデン・マニー・ニョロから選びました。初期2人の間は挑戦できません。自由枠を埋めるため田舎町まで進めて4人目を仲間にする案内を表示します。

加入済みの通常編成全員から4人を選べます。通常編成やセーブの並びは変えず、ラッシュの戦闘configにだけ4人を渡します。スーパーサブ・控えは空のため自動援護や追加交代はありません。開始時に人数・重複・必須・加入状態をUIと戦闘入口で検査します。開始後に戦闘不能者が出て生存者が3人になっても続行します。

## 必ず表示する演出

開始は博士の再構成・コード雨・走査線・進捗バー→博士案内→戦闘。ボスの各出現WAVEはシルエット→発光した姿→波紋の専用演出を一度ずつ表示してから行動を開始します。ボス判定は既存カテゴリboss／elite（中ボス）とフェニックス固有種別です。通常敵WAVEに同じボス演出を流しません。

完走／敗北は終了転送演出→博士案内→結果画面。中断やHOME帰還にも接続終了演出を入れます。完走報酬は最終勝利確定時に保存し、結果画面は終了演出後に表示。敗北・中断の完走報酬は0G。AREA途中クリアは継続扱いで、最終終了演出は流しません。ページを閉じた場合の演出は実行できず、再読込時の途中復帰はありません。

`presentation` の開始1800ms、終了1600ms、ボス2400ms、軽減450msと文言を編集できます。コード雨や画像再構成はCSS。OSの「動きを減らす」を尊重してアニメーションを止めても、短い転送画面は必ず表示します。「演出を短縮」「中断して戻る」を用意し、タイマー終了・短縮・中断が競合しても一度だけ遷移するよう処理します。激しい点滅は使用しません。

## 維持する報酬・敵・素材

コインは初回も周回も既存の6,000〜144,500G。今回のLv.下限変更では再計算しません。`clearCoins` が実額です。メダル性能、2〜3体編成、敵の元の行動回数・技・パッシブ、博士PNGとセリフは維持。敵テンプレートへの追加補正は行っていません。

開始時バックアップは `artifacts/rush-v255/backup/`。検証結果は `artifacts/rush-v255/`。他リポジトリ・素材原本は未変更、commit・push・公開なし。
