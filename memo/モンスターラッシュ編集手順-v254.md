# モンスターラッシュ v254 編集手順

旧14件を見直して16件追加した**合計30ステージ**です。各ステージにノーマル・ハード・インフェルノの3難度があります。4つ目の難度はありません。短編の1〜2 AREA構成と旧ステージ／メダルIDを維持しています。

## 編集するファイル

**`js/rush-v254.json` が今回の編集元です。** UTF-8のJSON形式で、博士ナレーション、敵編成、Lv.、技、パッシブ、行動数、解放条件、各難度のメダル性能を編集できます。旧 `js/rush-v252.json` は旧版の記録です。

```powershell
node scripts/build-v254.cjs
node --check js/game.js
node tests/rush-data-v254.cjs
node tests/rush-v254.cjs
node tests/rush-medals-v254.cjs
node tests/rush-ui-v254.cjs
```

ビルド後に `index.html` を再読み込みします。ローカルHTML起動も維持するため、ゲームはJSONから生成した埋め込みデータを読みます。JSONを変えただけでは反映されません。旧ビルド入口 `build-v252.cjs` / `build-v253.cjs` も現行版を生成します。生成済み `js/game.js` と `index.html` の中を直接編集しないでください。

実装は `js/rush-v254.js`、表示は `css/rush-v254.css`、検証は `js/rush-validation-v254.js`。旧v252/v253の進行・円形メダル基盤を継承し、ラッシュ用ブロック内だけに追加しています。`scripts/create-rush-v254.cjs` は初回生成用で、データが存在すると停止します。通常の編集では実行不要です。

## 博士のナレーション

キャラクター同士の会話を廃止し、`areas[].pre` / `post` の話者を `holo` に統一しています。音声やTTSは追加していません。ラッシュ内の戦闘中キャラクター台詞も非表示にしますが、その台詞に伴って起きる敵のパッシブ処理は残します。元の冒険やイベントの会話は変更しません。

```json
{"speaker":"holo","text":"編成データを受信っちゃ\n連戦テストを開始っちゃ"}
```

- 名前は `narrator.name` の「モブホロ博士」
- 「。」は使いません
- 各行の語尾は「っちゃ」、1行2〜18文字。短いロボ調の意味単位で `\n` 改行します
- 1レコードを1画面で表示します。画面の「次へ」で進みます
- `pre` はAREA開始、`post` はAREA完了です。途中のWAVEごとに長い会話を挟みません
- 敗北時の台詞は `narrator.defeat`、報酬受領・強化・AREA継続の文言は `narrator.messages` で編集できます

博士画像は承認済みv1（口なし・眉なし・シンプルな黒楕円目）の透明PNGを接続済みです。ユーザー保存の `Documents/素材集/hakase.png` をハッシュ照合・目視確認し、原本を残してコピーしました。`narrator.image` は `mqicon/mob-holo-professor-v254.png` です。

保存先：`mqicon/mob-holo-professor-v254.png`。承認済み原本のSHA256は `1d2767b3c4640fbeb1d362026c146ccd9cb2efef17f098a426e3201f3ff57f3d`。再接続する場合は原本を確認し、次を実行します。

```powershell
node scripts/connect-holo-v254.cjs
node tests/rush-ui-v254.cjs
```

この接続スクリプトは画像をダウンロードせず、上記ハッシュが一致する承認済み原本だけを接続します。UIは150×180pxの表示枠で画像の縦横比を維持し、下にホログラムの投影リングを表示します。

## 敵編成・AI・パッシブ

`areas[].waves` は各WAVEの配列で、各個体は `{ "enemy": "g-slime", "level": 7 }` の形式です。**すべての出現WAVEは2〜3体**。同種を重ねても構いません。倒された後に生存数が1体になることは通常の戦闘進行です。

`enemies` に各敵のテンプレートを収録しています。新規の標準行動数は通常敵1・中ボス2。既存データに明示された行動回数は優先し、フェニックス等の2〜3回行動も維持します。`actionCount` / `v144ActionMin` / `v144ActionMax` と `nativeActionCount` を確認してください。`enemySkills`、`special`、`specialOptions`、`v120ExtraSkills`、固有AIに従って魔法・特技を使用します。

全個体に `rushPassive` の「属性の解析障壁」を持たせ、指定属性耐性を6ポイント加算します。文字表示だけではなく、ラッシュ用テンプレートから作った敵に限って実際の耐性値へ反映します。元々その属性に弱い敵は、弱点を6ポイント緩和する意味になります。上限は75%。既存の反射、変身、回復、回避、軽減なども残します。属性障壁は個体自身に作用し、味方全体へ重複加算するバフではありません。

複数体化に合わせ、ラッシュ専用 `mods` で原則HP70%、ATK/MAG85%を適用しています。元の地域・イベント定義は変更しません。旧フェニックスは従来の短編補正HP30%を維持し、ATK/MAGは従来75%×85%です。その上に難度補正を掛けます。ボスは草原王・深海王・歴戦演習と旧フェニックスの一部WAVEに限定しています。

WAVE間は同じ戦闘を継続します。AREA間はHP・MP・死亡・状態異常を持ち越し、一時効果・ターンをリセットします。無料の全回復はありません。敗北・中断・HOME・ページ再読み込み後はAREA1から再挑戦です。

## メダルの性能・初回報酬・移行

全30枚×3難度の実加算値は [メダル性能一覧](モンスターラッシュメダル一覧-v254.md) に記載しています。

各ステージは固有メダル1枚だけを授与し、ハード／インフェルノでは**同じ所持メダルを強化**します。3難度で3枚にはなりません。クリア済み難度でも完走ごとに固定G報酬を受け取れます。メダル・経験値・通常ドロップは増えません。下位難度の再クリアでメダルが弱体化することもありません。

`medals[].tiers[0]` がノーマル、`[1]` がハード、`[2]` がインフェルノです。

- `stats`：武器基準の値。メダル装備では10%が実加算されます。例：ATK80 → ATK8、HP300 → HP30
- `traits`：既存の戦闘エンジンで実際に発動する効果。特性の割合は10%になりません
- `traitLabel`：`traits[].label` を ` / ` で連結した表示です。実値を変えたら百分率表示も合わせてください
- 同一IDを複数枠へ不正に重ねた場合も特性は1枚分です。通常の装備UIでは所持数を超えて装備できません
- 防御回復は防御行動時、MP軽減は対象属性の魔法のみ、毒は通常攻撃後の付与判定です。魔法MPは切り上げ計算のため小さい消費量では変化しない場合があります

耐久型はATKを抑えて防御時軽減／回復、狙撃型はSPD・会心、魔法型はMAG・MPと属性限定の消費軽減など、用途を分けました。インフェルノでも主な能力は実加算6〜8前後、耐性は7%前後です。既存URの単項ATK10や火闇耐性各15%を一律に上回らないようにしています。全30枚を持っても同時装備は既存枠数までです。

旧14件のIDとメダル所持数は維持します。旧 `meta.monsterRushV252[id]` はノーマル受領済みとして扱い、同じ報酬を再授与しません。新しい難度別記録は `meta.monsterRushV254[id].cleared`。強化性能は最高クリア難度から復元します。強化後に冒険チェックポイントへ戻っても、ラッシュの記録・所持メダルは保持します。

完走Gは各クエストの `clearCoins: [ノーマル, ハード, インフェルノ]` で編集します。初回と再戦は同額、500〜250,000Gの整数で、上位難度ほど高額にします。全AREA完走時に一度だけ支給・保存し、途中敗北／中断には完走Gを付与しません。装備・飲食の獲得倍率は固定完走報酬には適用しません。[全30件×3難度の変更前後一覧](モンスターラッシュコイン報酬-v254.md) を参照してください。`node tests/rush-coins-v254.cjs` で報酬経路を検証できます。

円形金縁・陰影・光沢・MEDAL表記は一覧、報酬、所持品、装備、装備選択に継続します。元モンスターPNGには手を加えません。
