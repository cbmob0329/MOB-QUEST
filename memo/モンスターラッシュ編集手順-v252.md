# モンスターラッシュ v252 編集手順

今回の追加は MOB-QUEST 内だけです。commit・push・公開はしていません。

## 遊び方と一覧

HOME → トレーニング → イベントクエスト → モンスターラッシュ。
ストーリー一覧の下にも同じ入口があります。各クエストは1回クリアで終了します。
未解放のカードも条件付きで表示しますが、報酬画像・モンスター名は解放するまで隠します。
テストモードでもこの4件の解放条件・受領済み判定は無効化しません。

| ID | クエスト | 解放条件 | 構成（数値はLv.） | 推奨Lv. |
|---|---|---|---|---|
| rush-grass-v252 | 草原の連戦稽古 | 草原クリア | AREA1: スライム7＋ロック7 → サバンナ9 → イワキリ10 | 10 |
| rush-rural-v252 | 田舎町の見張り稽古 | 田舎町クリア | AREA1: ナイフ19＋デンチマーク19 → スカウター21 → キャプテン23 | 23 |
| rush-magma-v252 | 炎と氷の連戦稽古 | マグマクリア | AREA1: マグゴーレム39 → ブリザード40 / AREA2: フレイム41 → フレザード43 | 43 |
| rush-ember-v252 | 灼熱の再挑戦 | 部族村クリア、復活！モブフェニックス！クリア | AREA1: マグゴーレム72 → フレイム73 → フレザード75 / AREA2: フェニックス80 | 80 |

すべて既存モンスター。冒険や元イベントの記録をラッシュの勝利で進めません。
通常敵は1行動、中ボスは2行動、フェニックスは2～3行動。最大同時出現2体。
WAVE間は同じ戦闘オブジェクトを維持するのでHP・MP・状態異常・一時強化・ターン数を引き継ぎます。
AREA間は既存イベントと同じ新規戦闘になり、HP・MP・死亡・状態異常を引き継ぎ、一時強化とターンはリセットします。
敗北・中断・HOME帰還・ページ再読み込みは挑戦終了。未クリアならAREA1から再挑戦できます。
途中再開機能はありません。通常冒険のチェックポイントやHPは書き換えません。

## 編集するファイル

- `js/rush-v252.json`：クエスト、セリフ、出現条件、敵、メダルの編集元（UTF-8 JSON）。
- `js/rush-v252.js`：画面・進行・受領処理。
- `js/rush-validation-v252.js`：ゲームとビルド共用のデータ検証。
- `css/rush-v252.css`：カードと結果画面。
- `mqicon/rush-v252.png`：新規共通ラッシュアイコン。
- `scripts/build-v252.cjs`：JSONと専用JS/CSSをゲームへ反映。
- `tests/rush-v252.cjs`：ブラウザーによる検証。

JSONを編集してから、MOB-QUESTフォルダで以下を実行してください。

```powershell
node scripts/build-v252.cjs
node --check js/game.js
node tests/rush-v252.cjs
```

その後 `index.html` を再読み込みします。ビルドは `js/game.js`、`css/style.css`、`index.html` のv252専用ブロックを更新します。
既存の単体HTML・file://起動との互換性を優先し、起動時のfetchには依存しません。
実行時はJSONから生成した `RUSH_DATA_V252` を直接読みます。JSON編集後は必ずビルドしてください。
他の更新をビルドした後も、必要に応じて最後にv252を再ビルドしてください。
生成済みの `js/game.js` / `index.html` 内のv252データを直接編集すると再ビルドで上書きされます。
`scripts/create-rush-data-v252.cjs` は最初の作成用で、既存JSONがあれば停止します。普段は実行しません。

## JSONの項目

- `quests[].id`：セーブ用の固定ID。公開・配布した後は変更しないこと。変更すると別クエスト扱いになり再報酬の原因になります。
- `title`：クエスト名。
- `world`：背景用地域ID。
- `recommendedLevel`：案内表示用。敵の強さそのものは `areas[].waves[][] .level` で設定。
- `unlock.world`：既存 `worldCleared` と同じ地域クリア条件。
- `unlock.story` と `unlock.record`：既存 `state.meta.storyEventsV179` のイベントキー・記録キー。フェニックスは `phoenix` / `clear`。存在しないキーは解放不能なので使わないこと。
- `unlock.label`：プレイヤーへ表示する条件説明。条件を変えたらこちらも変更。
- `reward`：`medals[].id` から1つ。数量は1に固定。
- `areas`：1～2件。`waves` は各AREA内の連戦。各WAVEは敵1～2体、全体は2～4 WAVE。
- `waves[][] .enemy`：`enemies` のキー。`level` は1～120。
- `pre` / `post`：AREA開始前・勝利後の会話。各行の `speaker` と `text` を編集。改行は `\n`。使用可能話者はpink、denden、money、nyoro、v179-phoenix。
- `enemies`：実際に既存ゲームから調べた敵テンプレートのコピー。画像・属性・技・技倍率・状態異常・耐性・軽減・回避・行動数を確認／編集できます。
- `actionCount`、`v144ActionMin`、`v144ActionMax`：基本値、毎ターン最小値・最大値。`forceActionCount:true` は維持。通常敵は1を推奨。
- `enemySkills` / `special` / `specialOptions` / `v120ExtraSkills`：既存戦闘エンジンが読む技。
- `elementResist` / `statusResist` / `damageReduction` / `evasion`：耐性・軽減・回避（0.05＝5%）。
- `mods`：敵ステータスの倍率。ラッシュのフェニックスは `hp:0.3, atk:0.75, mag:0.75` の稽古用補正。元イベントのフェニックスには適用しません。
- `medals[].stats`：装備画面の基礎値。メダル装備時の実加算は10%です。
- `medals[].traits`：効果自体は10%になりません。今回のkindはresist（属性耐性）とguardExtraCut（防御時追加軽減）。valueは小数、labelとtraitLabelは表示文です。
- `maxVisible:4`：ラッシュ専用一覧の上限。既存のストーリー／ボスカードを押し出しません。
- `maxSimultaneous:2`、`completionLimit:1`、`battleRewards:false`：安全上限と報酬方針。検証で固定／上限チェックします。

通常敵・中ボスのIDは既存の固有AIやパッシブを引く識別子でもあります。名称を変えたいだけならnameを変えてください。
フレザードの反射系パッシブ `v142Passive` とフェニックスの `story179Kind:'phoenix'` は既存JSに実装された能力を継承します。
特にフェニックスは水以外への耐性、毎ターン回復、HP半分で一度全回復、吸収、3ターン目の強化を残しています。
ただし追加の実戦闘エンジン検証で、元の能力値のままでは80ターンの消耗戦になったため、ラッシュ用テンプレートだけHP30%・ATK/MAG75%に調整しました。本人のセリフも「力を抑えた稽古」と分かる内容です。詳細な編成・装備・戦術・結果は `memo/モンスターラッシュ実戦検証-v252.md` を参照してください。
これらの固有能力の処理内容まで変える場合はJSONのラベルだけでなく既存 `js/update-v179.js` 等の実装理解が必要です。
ラッシュだけの調整は新しい固有ID／専用フックで行い、元イベントの共有処理を無闇に変更しないでください。

## 報酬とバランス

| 報酬 | レア度 | JSON基礎値 → 装備時の実加算 | 効果 |
|---|---|---|---|
| サバンナ・連戦の証 | SR | DEF30、HP100 → DEF3、HP10 | 地耐性3% |
| キャプテン・連戦の証 | SR | ATK40、MP100 → ATK4、MP10 | 闇耐性5% |
| フレザード・連戦の証 | SSR | MAG40、MND40 → MAG4、MND4 | 火・水耐性各5% |
| マグゴーレム・連戦の証 | SSR | DEF50、HP200 → DEF5、HP20 | 防御時の追加軽減5% |

比較した既存報酬は、ファイトSSR（ATK5・DEF5、低HP軽減5%）、カスタードUR（MAG5・MND5、魔法会心4%）、マカロンUR（ATK10、追撃3%）、ドラゴンUR（ATK5・DEF5・HP20、火闇耐性各15%）。
短編で得る4枚は通常装備の置換を避ける控えめな補助性能です。早期の2枚は特に小さく、後半もURを上回る耐性・追撃を付けません。
敵Lv.は既存地域終盤（草原ボス8、田舎町ボス帯、マグマボス40）付近から少し上。フェニックスは元イベント75～80相当を踏襲し、元イベント達成を必須にします。
同時に複数の中ボスを出す代わりに順番に出し、行動密度を抑えつつ回復資源管理が必要な設計です。
経験値・コイン・ダイヤ・フィギュア・通常ドロップは一切なし。各メダル1枚だけで、途中中断の反復で稼げません。
強さの最終的な体感は装備・キャラクター・手動操作で変わるため、推奨Lv.でのプレイヤー試遊を行って調整してください。

## セーブとバックアップ

クリア記録は既存metaに追加する `monsterRushV252[questId]` のみ。既存のストーリー記録・冒険進行・装備・通貨は変更しません。
メダル所持数とクリアフラグを同じmeta保存で確定します。最終勝利時に付与し、その後のセリフ中に閉じても二重受領しません。
敗北や中断ではクリアフラグを付けません。二重クリック・複数の終了コールでも同じ挑戦の報酬は増えません。
ローカルストレージを別タブから同時操作する一般的な競合や、ユーザーが手作業でセーブを書き換える操作までは保証しません。
今回の編集前コピーは `artifacts/rush-v252/backup/`（index.html、js_game.js、css_style.css）。ユーザーの実セーブは操作せず、テストは一時ブラウザーの隔離ストレージを使用しました。
他の変更が入った後にこのバックアップを丸ごと戻すとそれを失うので、復元時は差分を確認してください。
